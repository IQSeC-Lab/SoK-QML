# SoK: Critical Evaluation of Quantum Machine Learning for Adversarial Robustness

This repository contains the implementation framework and experimental setup for our study on quantum machine learning. It aims to support researchers by providing reproducible code, detailed architecture of the Quantum Multilayer Perceptron (QMLP), and technical design choices explored during the evaluation of adversarial robustness in quantum models.
